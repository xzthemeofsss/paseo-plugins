# Listing images

- `settings.en.png`, `settings.zh-CN.png` and `settings.dark.en.png` are unedited screenshots of the actual Link Pilot settings contribution inside the official Paseo web client, captured on 2026-10-27 with the local 0.13.0 daemon. The settings controls are available on web; link interception is desktop-only. Default values are shown. The images contain no chat content, file paths or credentials.
- `icon.svg` is the editable source for `icon.png`. Render it with Sharp at its native 256 × 256 size. Sharp is an authoring tool and is not a plugin dependency.
